GoGitOps → NetEnv Key Rotation

agents adopt netenv encryption on first key rotation — zero-touch sync

Agent Behavior

  • • Reads netenv_url from node YAML config
  • • Fetches active key version on every cycle (60s)
  • • Reports key_version back to netenv via checkin
  • • Detects rotation: adopts new version instantly
  • • CLI flags override: -netenv, -netenv-token

NetEnv Server Role

  • • Serves key state via GET /v1/keys
  • • Tracks node key versions in DB
  • • Auto-rotates keys every 90 days
  • • UI shows node sync: ✅ in sync / ⚠️ behind / ⏳ pending
  • • Alerts on overdue or stuck rotations

Adoption Pattern

  • • Agent connects → gets active_version → adopts
  • • Rotation happens → agent picks up v_next
  • • No agent-side key management needed
  • • nenv: references resolve from netenv itself
  • • Same pattern as dnclient CA rotation
